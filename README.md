# Joltio skills

Official Joltio skills and MCP connector, plugin version 1.1.0. This repository is generated by Joltio CI from the plugin source. Do not edit this published snapshot by hand. For support, use https://joltio.app/contact.

The connector alone already serves the skills your workspace allows through skills_get and MCP resources. Installing these local skills is optional. Local documentation describes the public plan; the server enforces your workspace permissions and plan on every request.

## Claude Code

Run these commands inside Claude Code:

```text
/plugin marketplace add datons/joltio-skills
/plugin install joltio@joltio-skills
```

The plugin installs both skills and the HTTP MCP connector at https://api.joltio.app/mcp. Open /mcp and authenticate the plugin's Joltio server with your Joltio account through OAuth. No API key or client secret is bundled. If you already configured this connector manually, keep only one active connection to avoid duplicate tools.

To update, run these commands in your shell:

```sh
claude plugin marketplace update joltio-skills
claude plugin update joltio@joltio-skills
```

See the [Claude Code plugin MCP documentation](https://code.claude.com/docs/en/mcp#plugin-provided-mcp-servers).

## Codex

Ask Codex's built-in skill-installer: "Install the skills from https://github.com/datons/joltio-skills at plugins/joltio/skills/joltio-artifacts and plugins/joltio/skills/joltio-data." The skills become available on the next turn. Installing skills does not configure MCP; register and authenticate the connector separately:

```sh
codex mcp add joltio --url https://api.joltio.app/mcp
codex mcp login joltio
```

Alternatively, copy each skill folder from plugins/joltio/skills/ into your project's .agents/skills/. Keep its SKILL.md and references together. See [Codex skills](https://developers.openai.com/codex/skills) and [Codex MCP](https://developers.openai.com/codex/mcp).

## Cursor

Download or clone this repository, then copy each folder from plugins/joltio/skills/ into your project's .cursor/skills/ (or ~/.cursor/skills/ for user-wide use), preserving references. Restart Cursor to discover the skills. This is a Claude Code marketplace; importing it as a Cursor marketplace is not supported.

Merge this server entry into your existing .cursor/mcp.json (project) or ~/.cursor/mcp.json (user), preserving other servers:

```json
{
  "mcpServers": {
    "joltio": {
      "url": "https://api.joltio.app/mcp"
    }
  }
}
```

In Cursor's MCP settings, connect Joltio and complete the OAuth sign-in. No key is needed. See [Cursor skill directories](https://cursor.com/docs/skills#skill-directories) and [Cursor MCP configuration](https://cursor.com/docs/mcp#using-mcpjson).

## Claude.ai and other chats

Add https://api.joltio.app/mcp as a custom connector and sign in with your Joltio account. You do not need this repository or a plugin. Follow the [connector instructions](https://joltio.app/data/docs/access#claude) ([español](https://joltio.app/es/data/docs/acceso#claude)).
